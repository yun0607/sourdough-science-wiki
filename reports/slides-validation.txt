- 圖像設計，第 1 輪：第 3 頁以圖說區分二氧化碳與有機酸。第 4 頁先後兩罐都有可區分的菌群示意。獨立複查通過。
- CSS 排版：首次截圖看到封面右側空間足夠，左側短句仍被段落寬度限制提早換行。放寬封面段落後複看。無實測溢出或遮擋。本項為 1 次排版微調。
- 瀏覽器驗證工具：重用前階段腳本時，一個 Python 多行替換字串的語法錯誤和下游 node --check 的不完整腳本錯誤，在啟動 Chrome 前同輪修正。
- Chrome 初跑在參考來源對話框的 Escape 測試得到 open=true，退出 1。排版及翻頁檢查此前已通過。回到測試輸入，補送 Escape 的虛擬鍵碼後，對話框以原生鍵盤行為關閉，簡報 JS 實作維持原狀。
- 第二次實跑全部檢查有 PASS 輸出，但測試伺服器連線仍未釋放，該執行以 Ctrl+C 收尾，退出 130。修正工具收尾，關閉 Chrome 管道與本機 HTTP 連線，第三次整體退出 0。
- 公開 Wiki 網址回查：網頁工具無法存取，curl -I -L --max-time 10 回 DNS 解析錯誤（退出 6）。GitHub Pages 專案子路徑及返回 Wiki 改以本機 /sourdough-science-wiki/slides/ 實測，沒有對遠端做部署驗收。
